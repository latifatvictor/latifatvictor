## ⚙️ PowerShell Automation Projects

> Scripts designed to reduce manual effort, improve consistency, and strengthen governance.

### 👤 Identity & Lifecycle

| Script | Purpose |
|---|---|
| **User Onboarding Automation** | Automates user creation, provisioning, group assignments, and licence allocation |
| **User Offboarding Automation** | Automates account deactivation, access removal, and mailbox handling |
| **Licence Assignment Automation** | Allocates M365 licences dynamically based on user roles and departments |
| **Inactive Users Report** | Identifies dormant accounts to support licence optimisation and security hygiene |

### 🔐 Security & Governance

| Script | Purpose |
|---|---|
| **MFA Reporting Script** | Generates MFA status reports across all users for security posture monitoring |
| **Privileged Access / Role Audit** | Reports on elevated access and admin role assignments |
| **Conditional Access Posture Report** | Maps policy coverage and highlights gaps in security controls |
| **Access Review Automation** | Supports periodic access reviews to remove inappropriate or outdated access |
| **Mailbox Permission Audit** | Reviews mailbox access and delegated permissions for governance readiness |

### 💻 Endpoint & Operations

| Script | Purpose |
|---|---|
| **Device Cleanup Script (Intune)** | Identifies and removes stale/inactive devices to improve endpoint hygiene |
| **Password Reset Script** | Automates password reset processes to improve response time and user experience |
